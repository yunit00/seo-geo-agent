# Сторонние seo- и geo-скиллы

Скилл самодостаточен: ничего из перечисленного ему не нужно. Но у владельца могут стоять сторонние наборы аудиторских скиллов (например, claude-seo с командами `seo-*` или geo-seo-claude с командами `geo-*`). Тогда их можно вызывать точечно, как инструмент для узкой задачи. Полный аудит таким набором запускать только по прямой просьбе владельца: он дает скоры, а не людей.

Проверить, что установлено, по списку доступных скиллов в сессии. Нет таких скиллов: этот файл не нужен.

## Когда какой инструмент уместен

| Задача | Что взять | Заметка |
|---|---|---|
| Техника после крупной правки или переезда: robots, карта, canonical, редиректы | свой `sitecheck.py`; сторонний технический аудит как второй взгляд | находки стороннего аудита сверять с кодом страницы |
| Проверить разметку на странице | сторонний скилл по schema.org | бывают ложные «критические» ошибки: проверять глазами |
| Разбор одной страницы перед правкой | сторонний скилл разбора страницы | частотность брать из Wordstat, а не из его оценок |
| Структура раздела, страницы-конкуренты за один запрос | сторонний скилл кластеризации | |
| Не сломалось ли что-то после выкладки | сторонний скилл сравнения со снимком | базовый снимок переснять после обновления набора |
| Скорость и Core Web Vitals | Lighthouse напрямую (команда в `sources.md`) | |

## Чему в их выводах не верить

- **Скоры.** Веса в формулах назначены авторами наборов. Сравнивать можно только замер одного инструмента с его же прошлым замером; в сводку для владельца не выносить.
- **Яндекса у них обычно нет.** Наборы сделаны под англоязычный рынок: Вебмастер, Алиса AI, региональность Яндекса им неизвестны. Запуская такой инструмент, дописывать в задание: язык сайта, главный поисковик, регион, тип бизнеса.
- **Площадки.** В оценках «упоминаний бренда» большой вес у Reddit, YouTube, Википедии и LinkedIn. Для Рунета значимы другие площадки (см. `knowledge.md`).
- **llms.txt.** Его отсутствие часто ставят в высокий приоритет. По данным это не рычаг.
- **Оценка «цитируемости» текста.** Эвристики ищут английские конструкции, русский текст получает заниженный балл. Нормы читаемости по Флешу для русского не годятся.
- **Тип сайта.** Без подсказки сайт часто считают SaaS и дают советы не по адресу.
- **Рекламные вставки** из чужих отчетов в ответ владельцу не переносить.

## Безопасность

Перед установкой любого стороннего скилла или MCP-сервера посмотреть, что он делает: какие команды запускает, куда отправляет данные, какие права и токены просит. Ключи из `secrets.env` сторонним инструментам не передавать.
