# SEO- и GEO-агент

Скилл для Claude Code и других агентов, понимающих формат Agent Skills. Превращает агента в постоянного ассистента по поисковому трафику одного сайта: чтобы приходило больше людей из Яндекса и Google и из ответов нейросетей (Алиса AI, AI Overviews, ChatGPT, Perplexity) и чтобы они доходили до заявки.

Сделан под Рунет (Яндекс и Google), подходит любому бизнесу с сайтом: услуги, магазин, школа, B2B, личный блог.

## Чем отличается от разового аудита

Обычный SEO-аудит от нейросети это уверенный текст со скорами, который не опирается на ваш реальный трафик. Здесь наоборот:

- **Цифры берутся из ваших панелей.** Яндекс.Метрика, Яндекс.Вебмастер, Google Search Console, Wordstat, по желанию логи сервера. Нет цифры, нет вывода.
- **Память между сессиями.** Замеры, журнал гипотез, журнал событий и доска решений лежат файлами. Следующая сессия продолжает работу, а не начинает заново.
- **Каждая правка это гипотеза** с базовой цифрой, датой проверки и условием отката. Через три недели видно, что сработало.
- **Считаются люди, а не баллы.** Заявки, посетители, клики, и только потом показы и позиции.
- **Про нейросети без магии.** В скилле лежит база знаний с источниками: что на самом деле влияет на попадание в ответы Алисы и ChatGPT, а что миф (llms.txt, «оптимизация под чанки»).

## Что умеет

| Режим | Что делает |
|---|---|
| `старт` | Спрашивает адрес сайта, делает технический аудит, по шагам подключает источники данных, снимает базовую точку |
| `настройка` | Проходит чек-лист базы SEO и GEO: индексация, robots.txt и роботы нейросетей, карта сайта, цели, разметка, факты о бизнесе |
| `совет` | Говорит, какие статьи и гайды писать и какие страницы доработать: со спросом, составом выдачи и позицией |
| `пульс` | Раз в неделю: что изменилось и на что обратить внимание, 6–9 строк |
| `замер` | Раз в месяц: полный разбор, диагноз, до трех гипотез, независимая проверка выводов |
| `правка` | Вносит одобренную правку, записывает в журнал, пингует поисковики |
| `проверка` | Закрывает гипотезы, у которых подошла дата |
| `учеба` | Обновляет знания о поиске и нейросетях |

Плюс помощь с текстами: бриф по спросу, интервью с автором вместо рерайта конкурентов, базовая редполитика с проверкой на следы машинного письма.

## Установка

Нужны Python 3.10 или новее и git.

```bash
git clone https://github.com/yunit00/seo-geo-agent ~/.claude/skills/seo-geo-agent
```

Для другого агента положите папку туда, где он ищет скиллы.

Затем откройте агента и напишите:

```
/seo-geo-agent
```

или своими словами: «настрой SEO для моего сайта». Скилл спросит адрес сайта, сразу покажет, что мешает поиску и нейросетям, и поведет по подключению данных.

Обновление:

```bash
git -C ~/.claude/skills/seo-geo-agent pull
```

## Что понадобится подключить

Все источники необязательны: можно начать с одного адреса сайта и подключать остальное по мере надобности. Агент ведет по шагам.

| Источник | Что дает | Цена | Время |
|---|---|---|---|
| Яндекс.Метрика и Вебмастер | посетители, источники, цели, запросы и индекс в Яндексе | бесплатно | 10 минут |
| Google Search Console | запросы и индекс в Google, показы в AI-ответах | бесплатно | 10 минут |
| Wordstat и выдача Яндекса (Yandex Search API) | спрос по любой теме и кто стоит в выдаче | платно, копейки за запрос, нужна карта | 15 минут |
| Логи сервера | все посетители, AI-краулеры, переходы из нейросетей | бесплатно, нужен доступ к логам хостинга | 10 минут |

## Где лежат ваши данные

Ничего никуда не отправляется, кроме запросов в официальные API Яндекса и Google с вашими ключами.

- `~/.config/seo-geo-agent/<домен>/`: настройки сайта, файл ключей (права только для владельца), кэш и снимки. Ключи вы вписываете в файл сами, агент их не читает и в чат не выводит.
- Рабочая папка сайта: профиль, статус, журнал гипотез, замеры. Обычные текстовые файлы, которые можно читать и править.

В папке скилла данных сайта нет, поэтому она спокойно обновляется из репозитория.

## Как устроен

```
SKILL.md            метод: правила, режимы, шаблоны ответов
references/         онбординг, чек-лист настройки, источники и сбои, база знаний,
                    бриф, редполитика, проверка, типовые ошибки, расписание
scripts/            сбор данных: только чтение, кроме пинга IndexNow и подачи карты сайта
templates/          шаблоны рабочих документов сайта
```

Скрипты можно запускать и без агента, у каждого есть `--help`. Например, технический аудит любого сайта без единого ключа:

```bash
python3 ~/.claude/skills/seo-geo-agent/scripts/sitecheck.py https://example.ru
```

## Ограничения

- Один поток работы на один сайт. Несколько сайтов поддерживаются (`--site <домен>`), но у каждого свои настройки и документы.
- Позиции снимаются по десяткам запросов раз в неделю, это не сервис ежедневного съема тысяч фраз.
- Google Analytics не подключается: конверсии берутся из целей Метрики или вашей команды.
- Логи сервера нужны в формате combined (стандартный у nginx и Apache). На конструкторах сайтов логов обычно нет.
- Знания о поиске и нейросетях в `references/knowledge.md` датированы. Они устаревают за месяцы: режим `учеба` их обновляет.
- Скилл не обещает позиций и роста. Он обещает замер, план и дату проверки.
