# Факты сайта: {{domain}}

Один источник правды для того, что сайт утверждает о бизнесе: цены, условия, сроки акций, названия тарифов, адреса, часы работы, цифры о компании. Чего здесь нет, о том в текстах не пишем, пока не сверили с владельцем.

Когда факт меняется, сначала правится строка здесь, потом скрипт ищет старое значение по всем страницам, разметке и llms.txt:

```bash
python3 <skill>/scripts/stale_facts.py
```

Он же входит в каждый снимок (`stale_facts.txt`) и отдельно напоминает о фактах, у которых вышел или выходит срок.

Колонки:
- **Старые значения**: регулярные выражения в обратных кавычках, без учета регистра. Неразрывные пробелы и `&nbsp;` перед поиском становятся обычным пробелом.
- **Можно рядом**: выражения для законных упоминаний старого значения в той же строке (например, «раньше стоило 3 900»). Такая строка ошибкой не считается.
- **Годен до**: дата, после которой факт заведомо меняется (конец акции, старт набора). Пусто, если срока нет.
- **Где правда**: откуда брать актуальное значение (прайс, касса, CRM, владелец).

Пример заполненных строк (в проверку не попадает, пока стоит в блоке кода):

```
| Консультация, цена | 4 900 ₽ | `3 900 ₽` `3900 ₽` | `раньше` | | прайс в CRM | 2026-11-25 |
| Скидка на первый заказ | 15% до 31 декабря | | | 2026-12-31 | владелец | 2026-11-25 |
```

| Факт | Сейчас | Старые значения | Можно рядом | Годен до | Где правда | Проверено |
|---|---|---|---|---|---|---|
